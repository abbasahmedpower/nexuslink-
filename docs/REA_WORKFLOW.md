# REA use in Nexus Hub
Source: https://github.com/morluto/rea (MIT; project code not vendored).
REA is a reverse engineering tool, NOT an Android-to-PC connection engine.
Use `npx rea-agents setup` to register developer AI tooling after reviewing its changes; use a supported Node version per upstream instructions.
For each investigation: question -> target checksum and provenance -> static or consented dynamic evidence -> unknowns -> implementation plan -> regression test -> review.
Review Phone Link only as permitted, for observable workflows and feature parity ideas; don't distribute copied graphics/code or circumvent service authentication. Prefer KDE Connect public protocol and scrcpy upstream documentation.
